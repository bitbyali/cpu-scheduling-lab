# آزمایشگاه زمان‌بندی پردازنده (CPU Scheduling Lab)

پلتفرم وب تعاملی، فارسی و راست‌چین برای شبیه‌سازی بصری و مقایسه الگوریتم‌های زمان‌بندی پردازنده **FCFS (First Come, First Served)** و **Round Robin** در درس سیستم‌عامل.

---

## ویژگی‌های کلیدی
- **موتور محاسباتی دقیق و مستقل:** منطبق بر قرارداد استاندارد کتاب *Operating System Concepts (Silberschatz)* در لحظات مرزی پایان کوانتوم.
- **کنترل کامل زمان منطقی:** اجرای خودکار (Play/Pause)، حرکت گام‌به‌گام به جلو و عقب (`Step Forward` / `Step Backward`)، بازنشانی (`Reset`)، پرش زمانی (`Seek`) و تنظیم سرعت (`0.5x` تا `4x`).
- **نمایش زنده CPU و صف آماده:** نمایش فرایند در حال اجرا، کوانتوم باقی‌مانده، صف آماده FIFO و وضعیت لحظه‌ای فرایندها (`Future`, `Ready`, `Running`, `Completed`).
- **نمودار گانت تعاملی:** نمایش بازه‌های اجرا و بیکاری (`Idle`) به همراه نشانگر زمان زنده.
- **جدول متریک‌ها و فرمول‌ها:** محاسبه دقیق `CT`، `TAT`، `WT` و `RT` به همراه میانگین‌ها و فرمول‌های فارسی.
- **نمای مقایسه هم‌زمان:** مقایسه مستقیم `FCFS` و `Round Robin` روی ورودی یکسان با قابلیت تغییر کوانتوم.
- **سناریوهای آماده ارائه دانشگاهی:** شامل مثال مرجع کلاس، پدیده اثر قطار (`Convoy Effect`)، ورود هم‌زمان و بازه بیکاری پردازنده.

---

## پیش‌نیازها
- **Node.js** نسخه `18.0.0` یا بالاتر
- **npm** نسخه `9.0.0` یا بالاتر

---

## نصب و اجرای محلی (Development)

۱. وارد پوشه پروژه شوید و وابستگی‌ها را نصب کنید:
```bash
npm install

````

۲. سرور توسعه Vite را اجرا کنید:

Bash

```
npm run dev

```

۳. آدرس نمایش‌داده‌شده در ترمینال (پیش‌فرض `http://localhost:5173`) را در مرورگر باز کنید.

## ساخت نسخه نهایی (Production Build)

۱. برای بررسی تایپ‌های TypeScript و ساخت پوشه بهینه `dist`:

Bash

```
npm run build

```

۲. برای پیش‌نمایش نسخه نهایی روی سیستم محلی:

Bash

```
npm run preview

```

خروجی نهایی در پوشه `dist/` قرار می‌گیرد و آماده استقرار روی وب‌سرورهایی مانند **Nginx** است. برای آموزش کامل نصب روی سرور لینوکس، فایل `DEPLOY.md` را مطالعه کنید.
